# blog-produtiva

Blog de insights da Produtiva Gestão, publicado em https://www.produtivagestao.com.br/blog/

- `index.html` é atualizado automaticamente todos os dias (por volta das 8h48) com um novo artigo.
- O servidor do site (cPanel) baixa este arquivo diariamente às 9h30 e substitui `public_html/blog/index.html`.
